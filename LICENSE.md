only**. It does not establish empirical, agronomic, legal, market, financial,
security, production, or multi-steward constitutional validation.

and open code (CAL-1.0) are the open tiers; the runtime **value / claim** code
(`prometheus-happ`, `prometheus-runtime`) is proprietary (`UNLICENSED`) and
gate-bound. The lowest unresolved gate controls the permitted claim.
